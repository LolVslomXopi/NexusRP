📖 Инструкция: где взять ключ?
Gemini (бесплатно):
1. Зайди на aistudio.google.com/apikey
2. Нажми «Create API Key»
3. Скопируй ключ вида AIzaSy...
4. Вставь в поле выше

DeepSeek (платно):
1. Зайди на platform.deepseek.com
2. Пополни баланс и создай ключ
3. Ключ вида sk-...

NVIDIA (бесплатно, без прокси):
1. Зайди на build.nvidia.com
2. Зарегистрируйся → «Get API Key»
3. Ключ вида nvapi-...
Сжатие документа памяти: низкая температура и запас токенов. Рекомендуется 3.5-flash-lite, t=0.2, 4096.
📖 Инструкция: зачем и как настроить прокси?
Зачем: Gemini заблокирован в России. Прокси-сервер (Cloudflare Worker) перенаправляет запросы к Gemini через себя, обходя блокировку.

Как сделать свой прокси:
1. Зайди на workers.cloudflare.com
2. Зарегистрируйся (бесплатно)
3. Нажми «Create Worker»
4. Вставь код из файла worker.js (который в папке rp-assistant-server)
5. Нажми «Deploy»
6. Скопируй URL вида https://твой-проект.workers.dev
7. Вставь его в поле выше

Готовый прокси: если не хочешь создавать свой — используй VPN (например, бесплатные ProtonVPN, Windscribe), он откроет прямой доступ к Gemini без прокси.
